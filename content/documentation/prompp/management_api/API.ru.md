Deckhouse Prom++ предоставляет набор API для управления, облегчающих автоматизацию и интеграцию.

## Проверка состояния здоровья

```yml
GET /-/healthy
HEAD /-/healthy
```

Этот эндпоинт всегда возвращает статус 200 и предназначен для проверки состояния здоровья Deckhouse Prom++.

## Проверка готовности

```yml
GET /-/ready
HEAD /-/ready
```

Этот эндпоинт возвращает статус 200, когда Deckhouse Prom++ готов обслуживать трафик (т.е. отвечать на запросы).

## Перезагрузка

```yml
PUT  /-/reload
POST /-/reload
```

Этот эндпоинт инициирует перезагрузку конфигурации Deckhouse Prom++ и файлов правил. По умолчанию он отключен и может быть включен с помощью флага `--web.enable-lifecycle`.
Альтернативно, перезагрузку конфигурации можно инициировать, отправив сигнал `SIGHUP` процессу Deckhouse Prom++.

## Завершение работы

```yml
PUT  /-/quit
POST /-/quit
```

Этот эндпоинт инициирует корректное завершение работы Deckhouse Prom++. По умолчанию он отключен и может быть включен с помощью флага `--web.enable-lifecycle`.
Альтернативно, корректное завершение работы можно инициировать, отправив сигнал `SIGTERM` процессу Deckhouse Prom++.
